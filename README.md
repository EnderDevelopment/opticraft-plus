# OptiCraft+

OptiCraft+ is a Minecraft mod designed to enhance the vanilla experience with a variety of quality-of-life improvements, optimizations, and additional features. This modpack includes mods and resource packs for animations, ensuring compatibility with shaders. Key features include infinite trading, enchanting infusers, ore excavation, and rudo locators, all while maintaining a vanilla-like feel.

## Install

1. Download the mod from the [GitHub repository](https://github.com/yourusername/OptiCraftPlus).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. Launch Minecraft and start a new world or load an existing one.
2. Access the various QoL features through the in-game menus:
   - **Infinite Trading**: Refresh trades infinitely.
   - **Enchanting Infuser**: Enhance your enchanting experience.
   - **Ore Excavation**: Efficiently mine ores.
   - **Rudo Locator**: Locate specific resources easily.
